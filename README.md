## 核心设定

### 主角
- **顾君**：31岁，国企程序员，历史考据型爱好者。木讷老实，不善社交。
- **白艺**：物理学博士，顾君的邻居。因读《太平年》被卷入副本。负责篇章中量子力学相关设定的科学解释。

### 核心规则
- 每个副本都是反派布下的恐怖陷阱，必须找到生门才能逃脱
- 所有被拉入副本的人都是"历史爱好者"
- 副本中存在"规则杀"——违反历史身份或超时即被鬼抹杀
- 鬼存在，但没有正义的神
- 一部分参与者会因错误的推理/阴谋论/历史发明行为而死（爽点来源）

### 核心冲突
- 反派卢夏（匈奴后人，隐藏的恨国贼）利用先祖获得的"石板"（量子规则操纵器）布下副本陷阱
- 七件国宝为主线器物：兰亭集序、马踏飞燕、佛骨舍利、清明上河图、永乐大典、传国玉玺、九鼎
- 最终反派利用石板将魔国/地狱与现实融合，华夏沦为人间地狱

## 写作规范（项目宪法）

### 字数
- 每章正文：2000字上下。不低于1500，不超过2500。
- 字数统计以汉字字符数为准（不含空格、标点、章节标题的装饰符号）。
- 写完后用 wc -m 验证。

### 对话密度
- 每章至少要有2-3组对话，通过对话体现人物性格。
- 张洋的贫嘴、刘峰的冲动、纪超的书呆子气、老莫的沉稳——都应该在对话中体现，而不是通过旁白描述。
- 如果一段超过200字没有引号，说明对话太少了，补。

### 信息释放节奏
- 禁忌词/大BOSS真名：最早Day 3才能由路人因触发而死来揭示，Day 4才由主角推理中正式提出。在前期全部用代称/谐音。
- 步数测试/空间验证：推迟到去找关键NPC的前一章。
- 祠堂秘密：Day 2发现但被阻挠，Day 4才能攻破。
- 池塘幻象：三幕渐进，不一次性放出。
- 路人的死亡：Day 2无人死亡，Day 3开始，Day 4最密集。
- 核心推理（串联全部线索）：在Day 4晚上看完所有幻象后，自然串联。

### 人物行为逻辑
- 问信息必须在自然对话中带出，不能为"让读者知道答案"而问。
- 角色的台词必须符合他当时的认知状态（不能问出他自己还不知道答案的问题）。
- 穿越/进入副本后，所有人默认觉得这是梦，不需要讨论"这是不是真的"。
- **每个人都必须觉得自己是历史爱好者。** 这是卢夏筛选参与者的标准——被拉进副本的人都是被"司隶校尉"论坛吸引的历史爱好者，他们可能水平参差不齐（考据党、阴谋论者、自媒体追随者、引经据典者），但没有人是"被误拉进来的路人"。周立说"我陪朋友来的"就违反了这条设定。每个路人对自己历史的兴趣应该有自己的表达方式——哪怕只有一个侧面，也必须存在。
