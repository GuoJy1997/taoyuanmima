# 第19章 又来？ 状态卡

## 关键事件
- 火光辨认：张洋（随身一次性打火机）与白艺找到顾君、秦华。白艺在下游醒来，循张洋火光跟来。
- 顾君向白艺、秦华讲述上一回桃花源经历；白艺尝试用量子力学解释，但点明量子是微观粒子规律，不适用宏观世界，未下定论。
- 老莫（自称莫怀山）带研究生苏晚晴，及路上碰见的三名路人（卫泽/方远/马川）登场。全程黑暗，各人靠声音自报身份。
- 老莫身上有打火机坚持一次不点，靠星辰辨向，强调"未知之地暴露自己最蠢"。
- 顾君讲面具人杀赵衡（人头落地）。三路人不信，唯卫泽当真——他上回也做过类似的梦（西汉末年王莽篡位场景），同伴接连死去。
- 顾君领悟：做这种梦的不止他们几人，且那些"没了"的同伴恐怕是真死了；此地自顾自运转，并非冲他们而来。
- 火把再亮（两处包抄）。竹林深处一浑身血的人（纪明）冲出求救，抓住顾君裤腿；铁青面具从竹后探出，獠牙上三道新鲜血痕。

## 新增伏笔
+ 卫泽西汉末年平行梦 → 多副本/多批人同时运转，"梦中会真死"跨副本规则铺垫
+ 老莫有打火机却一次不点、方向感绝对自信 → 沉稳可疑，主动入场线索
+ 铁青面具"獠牙"造型 → 天师道面具伏笔（按下不表）
+ 顾君对白艺"心里沉了一下" → 与白艺熟识邻居+暧昧未挑明的感情线延续（对齐间隙章015/016）
+ 方远"背后有组织在盯"的阴谋论 → 反派确实在暗中收割的错位反讽

## 角色状态
- 顾君：二次入梦，凭现象与声音判断处境，认知只到"面具人极危险、这种梦会死人"，不越界总结规则。
- 张洋：贫嘴缓解紧张，随身打火机是团队少数光源；对白艺卷入无特别反应。
- 白艺：首次入梦，冷静好奇，科学思路已启动但克制；与顾君熟识、暧昧未挑明。
- 秦华：法律顾问身份（伪装），持续压低众人、提醒别露光，缜密。
- 老莫：沉稳观察，只抛线索不解释来源，对赵衡之死"嗯"一声若有所悟。
- 苏晚晴：首次入梦，跟随老莫，尚未展开专业能力。
- 卫泽：历史发明家人格，因平行梦经历率先相信面具人之说，语气收敛。
- 方远：阴谋论人格，用"组织/被盯上"解释异常。
- 马川：反驳型人格，讥讽顾君"编恐怖片剧本"，全程不信。
- 纪明：路人，浑身血冲出求救即倒地，命悬一线。
- 赵衡：已死（第18章，人头落地被碾）。
