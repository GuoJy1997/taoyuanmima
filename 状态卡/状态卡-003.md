# 第3章 状态卡

## 关键事件
- Day 2白天：天空蓝得过分，云排列太整齐——"美得跟假的似的"
- 张洋贫嘴：“这天跟我小时候用的Windows XP壁纸似的”“好看是好看，就是假了点”
- 顾君问村民"在这儿多久了"→答案统一："记不得了""从小就住这儿""很久了"——记忆复读首次出现
- 张洋蹲路边和小孩玩——小孩穿锦缎衣服，袖口绣暗纹，领口镶银丝边
- 遇到姓余的中年人（实为庾）——衣服不合身（袖子长一截/下摆不对称）
- 遇到择菜妇人——眼睛没在看他们
- 中午后发现祠堂→门从里面锁了→老族长阻挠："那边不能去。有煞气。"
- 顾君拐过墙角回头——老人脸上笑容没了，表情复杂
- 铁锈味第一次出现：祠堂门缝下渗出的很淡气味——顾君不喜欢，加快步伐
- 天黑后村子安静得不正常，顾君回顾一天→"毕竟这是梦"→生物钟准时

## 新增伏笔
+ 天空"像假的" → 结界异常暗线启动
+ 村民记忆复读 → 执念体的特征
+ 小孩锦缎衣服 → Ch7祠堂暗格中的小孩衣服（物证回收）
+ 余=庾 → Ch11推理回收
+ 衣服不合身 → Ch10指认王栀之
+ 祠堂锁门+煞气 → Ch7翻窗进入
+ 铁锈味第一次（隐约/祠堂门缝） → Ch6第二次（浓/纪超倒地）→Ch9第三次（更浓/池塘方向）→Ch13揭示源头
+ 老人笑容消失 → 他对祠堂的态度不是保护而是恐惧

## 角色状态
- 顾君：收集信息，仍认为是梦，但铁锈味让他不舒服
- 张洋：活跃——和小孩玩、注意到衣服不合身、贫嘴保持
