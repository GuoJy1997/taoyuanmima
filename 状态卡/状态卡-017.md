# 第17章 水声先到 状态卡

## 关键事件
- 桃瓣消散后，顾君在深夜溪边醒来，时间感约为前一晚入睡后、凌晨一点前后。
- 顾君确认掌心淡金色光晕消失；身上仍是睡前衣服，袖口被溪水浸湿，空气中只有青草和湿泥味，没有铁锈味。
- 张洋最先与顾君碰头，延续“君儿”称呼和贫嘴节奏；顾君没有粗暴压制，而是用熟人间的冷幽默接梗。
- 老莫与苏晚晴出场。苏晚晴首次进入这场梦，出场即观察溪水、卵石水痕和流向。
- 秦华带着赵衡、方远、卫泽、纪明、马川到场，11人在溪边正式汇合；秦华等人均非首次入梦，出场时已有检查随身物、压低声音、讨论真实性的警觉。
- 五个路人建立外貌锚点：赵衡圆脸微胖穿运动外套；方远瘦长脸、黑框眼镜、抱鼓囊背包；卫泽高瘦尖下巴；纪明脸白厚镜片；马川寸头方脸粗脖子。
- 赵衡、方远、卫泽、纪明、马川分别表现出兴奋、阴谋论、典故联想、谨慎和反驳倾向，但无人确认具体地点与事件。
- 秦华只提供上游灯火和有人搬东西的模糊信息；众人没有接触岸边线索，没有确认年代、具体地点或具体仪式。
- 白艺从上游出现，起初不知道顾君等人的桃花源经历，只知道顾君此前问过“桃花源”。
- 顾君与白艺沟通后，才向她和其他人简述桃花源那次的关键生存信息：山洞、村子、看似安全的地方、不能乱说的名字、死人、王栀之和残卷，并强调如果这和上次一样，这里会死人。
- 白艺想起顾君在015章问过“观测效应”和“退相干”，追问桃瓣是在被看见后消散，还是被碰到后消散；顾君确认是碰到之后。
- 溪水中出现极短低嗡鸣；老莫判断天太黑，不适合立刻往上游灯火处走，众人暂时等待天亮。
- 结尾碎叶在石头旁短暂停住又被水带走，作为水流异常的第一处轻微信号。

## 新增伏笔
+ 上游灯火和夜里搬东西的声音 → 第18章沿水前行并逐步确认地点的入口
+ 白艺追问观测效应/退相干 → 承接015章对话，开启白艺物理视角的规则分析线
+ 溪水低嗡鸣与碎叶短暂停住 → 后续曲水、水流异常、仪式节奏线索
+ 11人仍穿睡前衣服、无身份说明 → 后续第18章规则确认前的铺垫
+ 卫泽将溪水联想到典故但未下结论 → 历史发明家性格与后续错误判断铺垫
+ 纪明坚持“先别下结论” → 后续依赖文献、遇事迟疑的行为线
+ 马川第一反应是找出口、否定他人判断 → 后续反驳老莫、赌气离队的性格铺垫

## 角色状态
- 顾君：从间隙章现实证据进入新一场梦；保持克制，没有提前确认地点，优先把桃花源那次能救命的信息告诉白艺。
- 张洋：贫嘴仍在，用玩笑缓解紧张；与顾君默契延续。
- 白艺：首次被卷入，起初不知道顾君等人的真实经历；听完顾君说明后想起015章观测效应/退相干对话，进入规则分析模式。
- 老莫：半明牌后继续沉稳，主张天亮前不要贸然往上游走。
- 苏晚晴：首次参团，高冷克制，先观察溪水与众人反应。
- 秦华：古道热肠、组织能力强；作为二次入梦者，先控场点人数，只提供自己看到的模糊信息，不替众人下结论。
- 赵衡：兴奋、浅尝辄止，容易被“古代文人山水场景”吸引。
- 方远：阴谋论倾向明显，认为背后有人操控。
- 卫泽：喜欢把历史场景往典故与暗线解释。
- 纪明：紧张怕乱，依赖谨慎判断。
- 马川：反驳型人格明显，第一反应是否定别人判断并寻找出口。
