# 第22章 陆续入场 状态卡

## 关键事件
- 秦华提议跟仆役原路出去，众人尾随。走到竹林深处撞上一道看不见的"墙"（无形壁）——凉硬、推不动、摸不到头；仆役却一个个穿墙离去。
- 顾君定论：同桃花源一样，不把这场活动走完就出不去；老莫赞同。最后的指望被摁灭，众人摸回溪边。
- 回到溪边，宾客陆续落座。张洋提议"既然看不见咱们，就像打游戏一样贴近拿情报"，率先大胆混入两案之间，安然无恙。老莫、苏晚晴、白艺随之猫腰散开贴身偷听。
- 唯马川不信，站远处讥笑"他们是装看不见，凑上去一把逮住"，不挪窝，被孤立。
- 老莫偷听两名中年宾客谈北方时事：中军策反落空、氐贼已据关中、白虏灭僭魏、"假孙子不沾王化"。老莫只在心里反复默记，不接话、不破解（守"说半句藏十句"人设）。
- 张洋、苏晚晴偷听两名年轻宾客：今日王家大宴、王家世代奉道，案上盒子"必为那物件"。张洋更好奇盒中何物。
- 一英气少年（桓伟，角色未知其名）带黑压压带刀侍卫山呼海啸入场，名流色变劝阻无用，少年满脸不屑径直前排落座。
- 秦华低声评侍卫杀气（死人堆里滚过、不止一回），断少年身份极高；顾君心弦更紧。

## 新增伏笔
+ 无形壁 + "不走完出不去" → 副本绑定规则，与桃花源同构，锁定主角团必须走完兰亭集会
+ 北方时事对话（中军/氐贼/白虏/僭魏/假孙子） → 第24章解码年代（约353年）与兰亭集会的关键情报，此章只记不破
+ 案上盒子=王家奉道之物 → 五石散/丹药线，后续服石仪式的伏笔
+ 英气少年+杀气侍卫（桓伟） → 桓氏军事势力，后续传国玉玺博弈的一方
+ 张洋"打游戏拿情报"混入 → 隐形期的利用方式，推动后续贴身偷听推进剧情

## 角色状态
- 顾君：确认副本绑定规则，主导判断，认知克制；对少年势力生出警觉。
- 张洋：大胆开创"混入偷听"打法，好奇盒中物，活跃推动。
- 白艺：跟进偷听，克制不下结论。
- 老莫：偷听北方时事只默记不破解，人设稳固。
- 苏晚晴：与张洋一处偷听，同样好奇盒子。
- 秦华：观察侍卫、精准判断少年身份，组织者兼行家。
- 卫泽：跟随，无独立戏份推进。
- 方远：阴谋论被摁下、未出口。
- 马川：独自站远讥笑不信，反驳型人格持续且被孤立。
- 存活名单：顾君/白艺/老莫/张洋/苏晚晴/秦华 + 卫泽/方远/马川（9人）不变。
