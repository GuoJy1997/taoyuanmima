# 第2章 状态卡

## 关键事件
- 8人穿过洞口，通道越走越窄→豁然开朗——土地平旷、屋舍俨然，和《桃花源记》一字不差
- 老族长（白头发老人）迎接："鄙人姓王。大家都叫我老族长。"安排食宿
- 张洋注意到村民衣着是晋制（交领、右衽）
- 吃饭场景：刘峰先试毒、纪超研究菜式、周立嘀咕"结构不对"、马晔反复看信号、老莫"那就不客气了"、张洋"试毒员已经上了，我再观察观察"
- 周立吐槽"但凡我今天加一粒花生米就不会做这种梦喽"
- 入夜：无灯、门窗关紧、油灯是唯一光源
- 张洋说"外面有东西"，顾君侧耳听——远处传来拖行声：沙、沙、沙，十几秒后停了
- 顾君发现手指是凉的、拳头不知什么时候攥紧了→慢慢松开
- 张洋"要不出去看看？"→顾君反问"看完呢？"→张洋躺回去"你说得对，当我没说"，翻身补一句"对个屁？明明是你懒得动"
- 结尾：只是没有人想醒来

## 新增伏笔
+ 拖行声 → 饿死鬼/影鬼预告（Ch7以更近距离重现）
+ 老族长过于自然的接待 → 后期揭示他是王羲之意志
+ 村里夜晚无虫鸣 → 环境异常第一步
+ 张洋贫嘴保持：“对个屁？明明是你懒得动”

## 角色状态
- 顾君：警觉，观察异常但未说破。拖行声后身体诚实——拳头攥紧
- 张洋：贫嘴（试毒员/对个屁）+怂（出去→不出去）——性格连续
- 老莫：低调，摆弄草茎，未特别表现
- 灰衣人：靠墙坐、不躺下、不说话
