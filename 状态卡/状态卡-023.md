# 第23章 重逢 状态卡

## 关键事件
- 会场座次大半填满，各年龄层入座。秦华格外留意坐中间、胡须浓密、谈吐条理分明、锋芒内敛的年轻人，低声评"了不得……假以时日不可限量"（角色未知其名，暗指后来大人物）。
- 竹林走入两人引骚动：一位容貌俊朗、沿途拱手寒暄、享受场合（谢万）；一位神色沉静、径直端坐、低声交谈听不真、举止自带分量压场（谢安）。苏晚晴久久注视、极轻"嘶"一声。
- 又一拨前呼后拥者到，为首衣冠散乱、自在放浪者（孙绰）大声抛出清谈"山涛吾所不解，吏非吏，隐非隐"，宾客抚掌"长史名言也"。秦华评"花架子会说漂亮话"，老莫却从中觉出线索、不明说。
- 最后一家人到场，内有气韵风流的孩童（张洋感叹大户教育），几名年长后生蓬头散发放浪形骸。顾君觉这几张脸眼熟却想不起在哪见过。
- 更高身份者鱼贯落座，仅剩主位空缺。顾君脑中翻找面貌，异样感渐重。
- 老莫鬼魅般挪到顾君身后低诵《兰亭集序》开篇（"永和九年，岁在癸丑……会于会稽山阴之兰亭"）。顾君记忆被点亮——最后这家人正是桃花源那座祠堂里见过的！
- 全场骤静，一人穿座席缓步走向主位，背影飘如游云、矫若惊龙、松弛、中等身量。转身——张洋、顾君与老莫互相对视，认出：是他！（桃花源里的"老族长"王右军）

+ 谢安式沉静压场者 + 谢万式俊朗寒暄者 → 谢氏势力入场，玉玺博弈的一方（角色暂不知名）

+ 主位者=桃花源"老族长" → 跨副本重逢，连续两梦相关的核心悬念，推动Ch24身份揭晓（王羲之）

## 角色状态
- 顾君：贴身观察记脸，被老莫一句点醒串通"桃花源祠堂—这家人"记忆；认出主位者是老族长，震惊。
- 张洋：贫嘴感叹贵族教育；同顾君一起认出老族长。
- 白艺：在场偷听观察，本章无独立台词推进（贴顾君附近）。
- 秦华：识人眼光展开——盛赞中间少年、看轻孙绰式清谈客，行家兼观察者。
- 老莫：全程"说半句藏十句"——觉出孙绰线索不说、以兰亭序开篇点破场合、与顾张共认老族长。
- 苏晚晴：对谢安式人物有强烈专业直觉（"嘶"），克制不言。
- 卫泽/方远/马川：本章隐于群体，无独立推进。
- 存活名单：顾君/白艺/老莫/张洋/苏晚晴/秦华 + 卫泽/方远/马川（9人）不变。
