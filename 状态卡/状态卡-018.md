# 第18章 晨往兰亭 状态卡

## 关键事件
- 天亮后，11人从溪边出发，沿山路和溪水往上游走。
- 路上遇见百姓临水祓除、洗濯不祥、采兰草，苏晚晴从兰草、柳枝、水边器物判断这是上巳祓禊。
- 众人只确认岸边有古人临水活动、上游有人设席待客，尚不知道这是什么集会。
- 众人确认NPC暂时看不见、碰不到他们：妇人不避让，少年绕过白艺时没有反应，老人水桶的水能沾湿马川鞋面，仆从竹竿从张洋胸口穿过。
- 白艺只确认“对方看不见我”，不提前总结规则，观测效应/退相干分析线暂时压住。
- 到达临溪空地，见大量席位、曲水、亭舍、酒器和试水木盘，只判断这里不是普通百姓洗濯。
- 几拨来客先后入场，主角团只能看出他们彼此有身份差异和互相避让，不能分辨具体家族/势力。
- 苏晚晴注意到瘦削老仆把压过油的黄纸塞入水道石缝，判断位置奇怪。
- 空席前笔砚纸先被摆好；溪水在笔尚未沾墨前短暂停住，被白艺注意到。

## 新增伏笔
+ 百姓祓禊与兰草 → 上巳节仪式入口，连接后续地点确认
+ NPC看不见/碰不到主角团 → 隐形期规则确认，后续“闪烁显形”规则基础
+ “他们看不见我” → 隐形期表层认知建立，观测/退相干分析线暂不明说
+ 大量席位与空席案 → 上游集会规模异常，后续势力博弈铺垫
+ 年轻公子随行排场不小、有人替他挡风 → 后续可回看的身份线索
+ 瘦削老仆压油纸入石缝 → 后续水道/符纸线索
+ 空席案前溪水短暂停住 → 曲水异常与仪式倒计时线索

## 角色状态
- 顾君：确认隐形状态和前方有大型临水活动，但不急于推理，只记住年轻公子排场、瘦削老仆和溪水停顿。
- 张洋：贫嘴持续，用吐槽缓解自己被竹竿穿过的惊吓；把年轻公子的排场吐槽成“领导视察”。
- 白艺：只确认NPC看不见自己，注意到空案前溪水停顿，暂未主动总结规则。
- 老莫：继续沉稳观察，即使看出一些端倪也只说“先看”，不主动解释完整答案。
- 苏晚晴：专业能力首次展开，从上巳祓禊、器物痕迹、油纸折法中判断异常。
- 秦华：保持组织者姿态，提醒众人别因看不见就乱动。
- 赵衡：从兴奋转为发白，意识到隐形不等于绝对安全。
- 方远：继续用现代阴谋/设备思路解释异常。
- 卫泽：认为前方阵仗不像普通春游，但没有得出具体结论。
- 纪明：谨慎跟随信息确认，仍不敢贸然下结论。
- 马川：持续反驳和催促，优先想找出口。
