# 第20章 惨死 状态卡

## 关键事件
- 承第19章：面具人举火把探出，火光压在纪明后颈。张洋要扶纪明，顾君去拦，秦华更快一步扣住二人后领往回死拖，纪明抓裤腿的手被扯脱。
- 面具人当众将纪明杀害（碎尸）。全程隔火光与黑暗，顾君被拽转身只看见一半：手臂反复抬落、竹上挂着淌血之物、湿柴掰断般的声响、温热溅到小腿。死法与赵衡"人头落地"不同，形成两种惨状。
- 顾君抓白艺、招呼张洋逃，秦华招呼三路人（卫泽/方远/马川），老莫早带苏晚晴退到最前。众人狂奔约半小时到极限，未走散。
- 逃出竹林至溪边开阔地。秦华指出开阔无掩体不宜久留。顾君见溪边有亭子，抹石凳无灰→判断有人常来且不久前来过，决定天亮找本地人当向导，暂躲百米外竹林。马川嘴上不服仍照做。
- 众人躲进竹林不敢睡，顾君向白艺讲桃花源惨状；白艺、苏晚晴皆感恐怖，马川讥"就这"，张洋回怼逗笑白艺，苏晚晴眉梢微弯旋即端正。
- 溪对岸来一群举火把、着宽袍大袖者布置场地。张洋、马川欲上前打招呼，被顾君、老莫、秦华同时按住。顾君定调：吃过桃花源轻信的亏，摸清底细前不露脸。
- 老莫、苏晚晴辨认服饰为交领右衽、褒衣博带的魏晋样式，同桃花源村民。顾君生不祥预感。天渐亮。

## 新增伏笔
+ 纪明碎尸 vs 赵衡人头落地 → 面具人杀法不一，misdirection（暗示面具人非普通刀手，实为规则抹杀的具象化，此时角色只当是凶手）
+ 亭中石凳无灰、有人常来 → 附近有活人/集会场地，天亮向导线索
+ 溪对岸魏晋服饰者布置场地 → 兰亭集会前置，与桃花源同代服饰的呼应
+ 秦华、老莫遇险时反应极快且判断精准 → 二人皆非寻常人的持续暗线

## 角色状态
- 顾君：目睹同伴惨死，强压生理反应主导撤离与决策；定下"不轻信古人"的行动方针，认知不越界。
- 张洋：受惊到失语，靠贫嘴（怼马川）自我缓解；仍冲动想找活人。
- 白艺：跟紧顾君，手腕发抖；听完桃花源事被恐怖笼罩。
- 秦华：关键时刻抢先救人、指出开阔地风险，组织者姿态稳固。
- 老莫：火把亮起即带苏晚晴先撤，靠服饰断代，沉稳可疑。
- 苏晚晴：专业能力初显——辨认交领右衽褒衣博带为魏晋样式；情绪克制端庄。
- 卫泽：逃亡中腿软被方远扶住，受惊但跟随。
- 方远：逃亡中扶住卫泽，暂无阴谋论发挥。
- 马川：反驳型人格持续，讥讽桃园经历、抱怨躲藏，仍照众人决定行动。
- 纪明：已死（面具人碎尸）。至此路人已死赵衡、纪明二人。
- 存活名单：顾君/白艺/老莫/张洋/苏晚晴/秦华 + 路人卫泽/方远/马川（共9人）。
