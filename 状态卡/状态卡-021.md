# 第21章 大会 状态卡

## 关键事件
- 天亮，众人藏竹林边沿（离对岸几十步、最近百米）观察对岸人群布置场地：沿溪排矮案，抬食盒、酒瓮。
- 秦华判断今天要办大事；张洋问服饰是否同桃花源，顾君答"像又不全像，领子袖子对不上"。
- 苏晚晴专业能力展开：断为东晋样式，大半是仆役（衣料纹路素净窄袖），器物多为酒器（耳杯/酒瓮/漆盘）。老莫借机点出她是门下最好的学生。
- 又一拨人涌出，为首两人戴同款鬼怪面具——竟有两个！众人惧。马川吓到失禁、转身要逃，正撞见第三个面具人（离三四步）。众人以为必死——面具人却径直走过，视若无睹，进会场与另两人低语。
- 一面具人从大布袋逐样取物、每案摆几个巴掌大的小盒；同时粗暴使唤仆役——踹倒磕破额头的老仆、吓跪抱漆盘的孩童（着重底层苦难）。顾君感慨仆役与昨夜死的纪明一样都是活人。
- 众人困惑：昨晚要杀，今天视而不见。方远阴谋论（未必一伙、只一个是凶手），张洋猜"盲人"，马川方远不屑。
- 白艺私下向顾君提出猜测："他是看不见我们"——瞎子耳鼻更灵，马川动静那么大却毫无察觉，反常。只陈述现象，不下规则定论。顾君会意她又往物理方向想。
- 场地摆好仆役全退，三面具人撤下随从独自留守。一面具人转头正对藏身竹林，众人惊，终又转开（自己吓自己）。
- 几名仆役折回走近，马川再露马脚（撞竹响、半身探出），仆役却视若无人径直离开。张洋道破荒唐念头："马川你会隐身啊？"

## 新增伏笔
+ 面具人对主角团视而不见、仆役从马川身边穿过无反应 → 隐形期规则的现象呈现（角色尚未参透）
+ 每案小盒（内为丹药/散） → 兰亭服石、五石散被掉包的前置线索
+ 三个面具人+粗暴使唤仆役 → 面具人实为某组织（天师道）成员、非单纯杀手的伏笔
+ 白艺"看不见我们"+物理直觉 → 观测/退相干规则解读线，继续压着不点破
+ 底层仆役苦难 → 作品兼写上层与底层，后续基调延续

## 角色状态
- 顾君：主导观察，压制推断，认知只到"面具人似乎看不见我们"的现象层，不越界总结规则。
- 张洋：贫嘴（"盲人"）缓解，却敏锐说破"马川会隐身"的直觉。
- 白艺：首次提出物理性猜测（看不见我们），克制不下结论。
- 秦华：判断今日办大事，观察者姿态稳固。
- 老莫：沉稳，借机点出苏晚晴专业。
- 苏晚晴：专业能力展开（东晋服饰、仆役身份、酒器），话少而精准。
- 卫泽：受惊退缩，无独立戏份推进。
- 方远：阴谋论（未必一伙）。
- 马川：受惊失禁+险逃，意外成为"隐身"现象的活体样本，反差强烈。
- 存活名单：顾君/白艺/老莫/张洋/苏晚晴/秦华 + 卫泽/方远/马川（9人）不变。
