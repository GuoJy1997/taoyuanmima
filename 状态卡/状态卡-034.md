# 第34章 大灾变 状态卡

## 关键事件
- 开场被十几个丧尸围住，"围得很慢，像围一桌酒"；打头者手里攥着活着时写的诗（血浸透，攥得指节发白）
- 秦华："它们看得见，可它们不一定分得清哪个更近"——主会场溃逃的哭喊引走尸群
- 逃出包围：从丧尸缝隙穿过（酒气+血腥气两步之内）；张洋绊飞耳杯，秦华半空抄住无声放回（身手）；苏晚晴袖子擦过丧尸衣角僵半拍，无反应，挪过
- 大灾变全景：尸变一片一片铺开（对岸→本岸→偏厢→廊下），"像有人拿着看不见的笔一片一片把人涂黑"
- 老莫看出规律："远的水边先发作，近主位的后发作——有什么东西在拖，拖不住了才一片一片塌"（杜子恭符箓时间差，读者可见不解释）
- 反讽特写：一行散名士被丧尸并排跑，还喊"同去同去"，被咬住脖子——"他到死大概都以为那是一起行散的同道"
- 掩护失效：第一声"他咬人！"；没人再笑、再说"合乎道法"；老名士喊"这是行散"被拖倒
- 喊出第一声的年轻名士被水里站起来的三个东西拖下浅滩（修禊下水者）
- 山羊须从偏厢方向出，尸群最快，"所过之处像镰刀割麦子"
- 仆从背主人逃，被扑倒压在底下还在喊"郎君快跑"
- 间谍线：乱局中几个人不跑，廊下阴影冷眼旁观；深目高颧不像汉人；老莫："乱成这样他们不跑，他们不是来赴会的。""记下。"→再看时已不见，只剩踩倒的草
- 偏厢一侧起火（山羊须被搀进去的偏厢）；顾君想：点火的人是烧东西，还是烧躲在里面的人
- 章末：溃逃人潮涌来，"抓稳旁边的人！"——顾君抓住白艺又被冲开，张洋的喊声听不见——七人被撕开，像撕开一张纸

## 新增伏笔
+ 一片一片爆发（远先近后）+老莫"有什么东西在拖" → 杜子恭镇灵符（第四幕）
+ 廊下冷眼旁观者（深目高颧、消失无踪） → 间谍线（后续密会目击/顾君揭韩卓的知识基础）
+ 偏厢起火 → 山羊须去向（后续再现）
+ 秦华半空抄杯无声（身手+1） → 秦华自身暗线

## 角色状态
- 顾君：两步内闻丧尸酒气血腥气；目击间谍线；被人潮撕开
- 白艺：见年轻名士被拖下水，别过脸；被人潮撕开
- 老莫：看出一片一片的规律（"有什么东西在拖"）；目击间谍（"记下"）
- 张洋：险发声（耳杯），被秦华救下
- 苏晚晴：袖子擦丧尸衣角险之又险；指出火从偏厢起
- 秦华：判断"它们分不清哪个更近"；半空抄杯
- 马川：随众人逃出包围
- 存活名单：7人不变（被人潮冲散）
