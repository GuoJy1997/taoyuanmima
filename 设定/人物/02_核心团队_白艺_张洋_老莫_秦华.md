# 核心探索小队档案

## 1. 白艺 (女主角 / 科学理性锚点)
- **身份**：物理学博士，顾君邻居。
- **特质**：极其聪明理性，思维敏锐。负责从量子退相干、光波频率、信息熵等物理角度解析结界异常。
- **声音指纹**：语调冷静平直，善于将怪诞现象拆解为可观测的物理指标。
- **当前状态（第36章末）**：手背擦伤渗血，衣衫湿透，与苏晚晴一同赶到石桥洞。

## 2. 张洋 (发小 / 情绪与嘴碎担当)
- **身份**：顾君的发小，普通人，怕死但关键时刻讲义气。
- **核心功能**：高压下的幽默感与贫嘴缓冲剂，代表普通读者的第一反应。
- **语言指纹**：
  - 说话带颤、嘴碎、爱吐槽（“合着这帮名士来聚会都带兵啊？总不能是来写诗的吧！”）；
  - 任何章节禁止写成老谋深算的高手，他的恐惧必须写在嘴上和动作上。

## 3. 老莫 (学者 / 战术定海神针)
- **身份**：退休历史系副教授。
- **特质**：沉稳、持重、阅历深厚。
- **功能**：掌舵人，善于安抚众人，协调战术撤退路径（本章的石桥洞即老莫事先选定的安全集合点）。

## 4. 苏晚晴 (同行者)
- **特质**：外冷内热，身手利落，危机中能保持战斗警觉。

## 5. 秦华 (极度危险的隐藏暗桩)
- **表面身份**：热心靠谱的同行老驴友，野外求生技能高超（第36章主动撕下外袍替白艺和苏晚晴包扎）。
- **真实隐藏身份**：反派卢夏座下核心爪牙，混入小队伺机引导白艺走向献祭点。
- **行为约束**：动作极其熟练专业，甚至伪装得比正人君子更像好人，决不可过早露出邪恶微笑等廉价 AI 反派嘴脸！
